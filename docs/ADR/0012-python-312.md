# ADR-0012: Python 3.12 pinned

Date: 2026-07-15 · Status: Accepted

## Context

The agreed stack is Python 3.12; uv otherwise resolves to the newest
available interpreter (3.14 at scaffold time), risking subtle
dependency incompatibilities.

## Decision

`.python-version` pins 3.12 in `apps/backend`; uv provisions the
interpreter automatically.

## Consequences

- Reproducible environments across machines and CI.
- Upgrading is a deliberate one-line change plus a full test run.
